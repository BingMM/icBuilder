#### Storing posterior model covariance

The posterior model covariance of the toy example takes up 650 MB in double precision.

Saving the lower triangular matrix from the Cholesky factorization and the permutation takes up 60 MB. However, this requires the posterior model covariance to be reconstructed upon loading the spline image. This can be done with lazy loading, saving time, as most usage wont depends on uncertainties.

The result is still a 130 MB file.

#### Resolution
Below are performance tests.
100% based on feelings.
The spatial control points will be set to ncp=30.
The temporal control points will be set to one every 6 min.
- This is the natural translation from 3 in the test below. Frames are ~2 min apart.

Model complexity goes from 9000 to 5400.
The posterior covariance matrix will be ~36% of the previous size.

This bring the spline image down to 60 MB
