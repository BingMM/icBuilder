# 2026-07-29 — Zhang–Paxton latitude collapse

## Scope

Populate the existing `scripts/ZhangPaxton2008_collapse.py` placeholder with a
human-readable MLAT reduction, generate explanatory figures, and preserve the
scientific questions that must be resolved before pipeline integration.

## Result

The script now locates the principal contiguous Q-defined oval in each
latitude slice and computes exact spherical-area-weighted conditional mean and
median E0. It exposes only the absolute 0.05 and 0.25 mW m-2 thresholds, plus
spread, Q-weighted sensitivity, selected bounds, area, empty-mask,
sampling-limit, and physical-pole diagnostics. The user explicitly rejected
the relative 10%-of-peak threshold.

Three PNG/PDF figure pairs show the two-dimensional selection process, an
annotated latitude slice, and the final Kp/MLT reduction with threshold
sensitivity. The latitude-slice figure shows both the area mean and median,
and its weight panel is correctly labelled as weights used in Step 2.
Diagnostic MLT sampling is 0.05 hour; the callable model remains continuous
and accepts arbitrary MLT inputs.

Seven focused tests, including a polar radial-orientation regression, AST
parsing, headless generation, and visual inspection passed. A comparison with
0.01-hour sampling found at most 0.037 keV interpolation error for the
area-mean product.

The user identified jitter in the final sensitivity curves and requested a
trial at 0.01-degree MLAT. The finer grid removed the visible staircase. For
the four plotted Kp/threshold curves, RMS second differences decreased from
0.016–0.023 keV at 0.25 degrees to 0.00095–0.00124 keV at 0.01 degrees. Model
evaluation was batched to keep the fine-grid calculation practical.

The user then confirmed the production-performance design: IMAGE frames share
a fixed 36-by-36 Cubed-Sphere grid, so the expensive fine-MLAT calculation
should be performed once per supported Kp state and stored as a grid lookup,
not repeated for each frame.

The user then made the integration role explicit. The Zhang–Paxton work was
introduced because tests against DMSP failed to reproduce the empirical
WIC/SI13-to-E0 relation proposed by Frey et al. (2003). The user therefore
chose to replace IMAGE-derived E0 and dE0 entirely, not retain them as a
fallback, blend, or calibration target.

The user rejected two proposed integration requirements. A separate automatic
IMAGE precipitation-support mask is not considered robustly achievable, so
corrected WIC brightness will supply the observed spatial amplitude without a
new inferred oval boundary. DMSP will not enter the replacement estimator or
its uncertainty calculation; its role here is only the failed validation that
motivated retiring the Frey relation.

The user specified that dE0 should come from the same Zhang–Paxton latitude
profile as the collapsed mean. The implemented spherical-area-weighted
`weighted_spread` is the direct scalar definition. It measures unresolved
latitude variability discarded by the collapse and must not be represented as
formal Zhang–Paxton model-fit uncertainty.

The remaining constraints are that arbitrary Kp must use the published
interpolation before collapse, the current zero E0–Fe covariance placeholder
must be revisited because Fe is calculated from E0, and Zhang–Paxton
mean-energy compatibility and SI13's remaining role must be resolved.

The default-threshold diagnostic grid revealed frequent contact with the
50-degree equatorward limit and the physical pole. This is durable evidence
that threshold choice must be reviewed rather than treated as settled.

The user requested a companion to the collapsed-mean result figure showing
dE0. `zhang_paxton_collapse_dE0_result.png` and PDF now map the existing
spherical-area-weighted `weighted_spread` over Kp/MLT and show the same Kp=2
and Kp=5 threshold-sensitivity curves. The mean and dE0 figures reuse one set
of expensive fine-latitude model evaluations. The focused tests remain seven
passing tests, all 27 Python files parse, and all four PNG outputs were
visually inspected.

SI13 was reconsidered without returning it to E0 inference. The proposed
initial role is optional validation: use Zhang–Paxton E0 and WIC-derived Fe to
predict corrected SI13 electron counts, then compare prediction with observed
corrected SI13. An equivalent diagnostic compares separate WIC- and
SI13-derived Fe estimates at fixed Zhang–Paxton E0. SI13 should not initially
be required for product generation or fused into Fe; a joint flux estimator
is only a later possibility if the validation succeeds and shared
uncertainties are handled.

No IMAGE pipeline was run and no production integration was implemented. The
replacement direction is now decided; its scientific compatibility,
uncertainty propagation and SI13 consequences remain open. The source of dE0
and the decision not to add a new support mask are now settled.

## Full repository audit

A later read-only audit examined the scientific E0 chain, preprocessing,
alignment, gridding, uncertainties, numerical code, representative products,
and reproducibility. The work used three independent audit tracks and then
reconciled their findings against live code and five tracked conductance
products.

The Frey table and WIC/SI13 orientation are correct. No simple coefficient
swap explains the failure. Orbit 0085 already has a median uncorrected binned
ratio near 208 for SI13 above three counts, above the response-table maximum
near 136.5. Across the five products, only about 1.7–11.2% of valid pixels are
interior-table E0 retrievals; most are exact fallback or saturation values.

The audit confirmed a malformed SI grid, unmatched 225/450-km effective
resolution, clipping and threshold discontinuities, a fixed 2-keV proton
assumption, invalid upper-saturation dE0, incomplete covariance, a Pedersen
spline uncertainty typo, and major dependency/test/provenance gaps. These
amplify local failures but do not explain the high ratio already present
before inversion and historically before background subtraction.

The strongest unresolved causal boundary is whether the instrument values are
normalized to the calibration and reference epoch assumed by the Frey
response, together with use of one standard-atmosphere/nadir curve across
disturbed conditions and viewing angles out to 75 degrees. The generated
products discard the metadata needed to resolve that question. The next
causal experiment is one documented calibrated, strong-signal, near-nadir
WIC/SI13 pair on common support and matched resolution. Full findings and the
recommended repair order are recorded in
[[../02_Algorithm/Audit - 2026-07-29]].

No production code or data were changed by the audit.
