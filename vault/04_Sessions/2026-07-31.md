# Zhang--Paxton collapse refactor

Last reviewed: 2026-07-31

The reusable latitude collapse was separated from its diagnostic plotting and
CLI. `icbuilder/zhang_paxton_collapse.py` now shows the scientific calculation
directly and returns ordinary dictionaries; plotting remains in
`scripts/ZhangPaxton2008_collapse.py`.

Exact old/new comparisons covered scalar and broadcast calls, Kp 0--9 over 48
MLT values, both absolute thresholds, empty and disconnected intervals,
non-finite data, and all domain-contact flags. All values were identical. The
four figure sets regenerated and were visually checked. The bundled lookup
checksum did not change, so it does not need regeneration.
