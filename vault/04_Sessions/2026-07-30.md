# 2026-07-30 — Fixed-grid Zhang–Paxton lookup

## Scope

Implement the precomputed electron-energy lookup on the actual IMAGE
Cubed-Sphere grid. The user clarified that the spatial axes must remain
`(xi, eta)` because MLT is two-dimensional, and selected direct Kp levels at
0.01 spacing with nearest-hundredth runtime quantization.

## Result

Grid construction is now centralized in `icbuilder/grids.py`. The production
orbit script and lookup builder therefore use the same 36-by-36 WIC grid and
exactly nested 18-by-18 SI grid. The WIC grid has a two-dimensional
cell-centre MLT coordinate `(grid.lon / 15) % 24`.

The reusable collapse moved from the plotting script into
`icbuilder/zhang_paxton_collapse.py`; the original script path remains a thin
wrapper. `icbuilder/zhang_paxton_lookup.py` now provides:

- resumable, optionally parallel generation of all 901 Kp layers;
- a compressed, self-describing NetCDF format with grid and scientific
  provenance;
- strict grid-signature and completeness validation;
- direct scalar or vector lookup after rounding Kp to the nearest 0.01.

The completed bundled table is
`icbuilder/data/zhang_paxton_e0_lookup_v1.nc`, 14 MB, with dimensions
`(901, 36, 36)`. It stores mean E0, profile-spread dE0, area median, selected
latitude bounds, and selection flags. It uses ZhangPaxton2008 0.1.0,
`Q > 0.05 mW m-2`, and 0.01-degree MLAT cells over 50--90 degrees.

All 20 focused tests pass. Lookup values at selected Kp=1.52 cells agree with
direct collapses to float32 storage precision. The native-grid diagnostic
`figures/zhang_paxton_lookup_kp1_52.png` and PDF were visually inspected.

## Remaining boundary

The lookup is technically complete but not yet wired into
`ConductanceImage`. The table has no empty selections, but 231,123 of
1,167,696 cells touch the provisional 50-degree equatorward sampling limit.
Threshold/domain approval, mean-energy compatibility, frame-time Kp
acquisition/provenance, Fe calculation, and E0--Fe uncertainty dependence
remain integration tasks.
