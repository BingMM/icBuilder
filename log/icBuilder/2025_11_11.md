
Running tests on a full orbit ~300 frames results in .nc files around 600 MB. The majority of which is the model variance.

The code has been refactored introducing a new internal solver class to minimize code redundancy.

#### Data variance:
The data uncertainty was not squared resulting in severe underestimation of the model variance.

Fixing this has resulting in a significant reduction of the regularization parameter. This must be a bug as it is scaled with the sensitivity matrix.
- *Not a bug*: There are substantial differences in the magnitude of the data uncertainty. This is emphasized much more when squared. The scaling wrt. median of the diagonal of the sensitivity matrix changes.
